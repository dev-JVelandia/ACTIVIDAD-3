Estos son tres trabajos que hice en clase mientras estudio desarrollo de software. Cada uno explica qué hace y tiene el enlace a su repositorio en GitHub.

Generador de Horarios para Estudiantes

Aplicación de consola en Python para organizar el horario semanal de un estudiante: materias y actividades con su día, hora y ubicación.

  • Registrar, modificar y eliminar materias o actividades.
  • Mostrar el calendario semanal como una tabla por día y hora.
  • Validar el nombre, el día, el formato de las horas y los cruces de horario.
  • Guardar los datos en un archivo JSON.

Python · JSON

Generador de Horarios, versión con reporte
